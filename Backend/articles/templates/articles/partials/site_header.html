{% comment %} The site header, server-rendered. This is the same two-row header the React Navbar draws, built here because the article pages are Django templates and cannot mount React. It is a deliberate duplication of a component, not a fork of the design: every value below comes from Design.md §8 — white surface, subtle bottom hairline, 72px top row with the logo leading and the account and cart controls trailing, then a 44px centred link row. What it deliberately does NOT duplicate is state. The React header shows the signed-in phone number and a live cart count; a server-rendered page knows neither, and printing a guessed "0" would be worse than printing nothing. So the controls here are quiet links to the same destinations, and the count badge is simply absent. Keep the link set and the order in step with the `categories` array in Frontend/salyco-front/src/components/Navbar.jsx. Those five labels are §8's main links, and a visitor crossing between the two halves of the site should not see the navigation change shape. {% endcomment %}
